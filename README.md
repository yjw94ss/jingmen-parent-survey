# 荆门儿童AI创意体验｜家长需求调研

把纸质/Excel 版《家长需求调研表》做成网页问卷，家长在线填写，答卷自动汇总到管理后台。

## 页面

| 文件 | 用途 |
|---|---|
| `index.html` | 家长填写页（匿名，约 3–4 分钟） |
| `admin.html` | 管理后台（口令进入，看统计 / 导出） |
| `assets/questions.js` | 14 道题目定义（家长端与后台共用） |
| `assets/store.js` | 数据访问层 |
| `assets/survey.js` | 家长端交互 |
| `assets/admin.js` | 后台逻辑 |
| `assets/style.css` / `assets/admin.css` | 样式（暗色主题、移动端优先） |

## 使用

**家长**：打开 `index.html`，勾选后点「提交问卷」。

**你**：打开 `admin.html`，输入口令（默认 `jingmen2026`，建议在 `admin.html` 的 `<body>` 上加 `data-pw="你的口令"` 改掉），可以看到：

- 总份数
- **分布统计** — 13 道非开放题的逐项人数与占比
- **交叉分析** — 任选一个维度看各选项人数分布
- **开放建议** — 家长写的第 14 题原文，按年龄/区域标注
- **全部答卷** — 每份答卷逐题展开，可单条删除
- **使用说明** — 原表里的样本量、价格题口径、合规提醒等 10 条

**导出**：CSV（Excel/WPS 直接打开）或 Excel（`.xlsx`）。

## 数据说明

`assets/store.js` 里的 `config` 字段接入云端数据库后会写入答卷；未接入时只保留在当前页面内存，页面会明确提示「刷新即丢失」，不会假装保存成功。

## 题目结构

四个板块，对应原表：

1. 孩子与家庭情况（Q01–Q04）
2. 学习需求与关注点（Q05–Q08）
3. 体验形式与付费意愿（Q09–Q13）
4. 开放建议（Q14）

限选规则已在家长端生效：Q05/Q07 最多选 3 项，Q06/Q08 最多选 2 项，超出会拦截并提示。

## 统计口径提醒

所有比例与样本分布仅作市场验证。请关注不同年龄段与区域家长的差异；多选题人数之和会超过总样本数，属于正常。不应以样本数量直接推算全市市场规模。
