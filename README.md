# 荆门儿童AI创意体验｜家长需求调研

把《家长需求调研表》做成网页问卷。家长在线勾选 → 生成一段结果文字发回 → 导入后台自动汇总统计。

## 线上地址

- 家长填写页：<https://yjw94ss.github.io/jingmen-parent-survey/>
- 管理后台：<https://yjw94ss.github.io/jingmen-parent-survey/admin.html>（默认口令 `jingmen2026`）

## 怎么用（三步）

**1. 家长填写**

把家长填写页链接（可发微信群、二维码）发出去。家长勾完 14 题点提交，页面会给出一段以「【荆门儿童AI创意体验·家长需求调研】」开头的文字，并提供「复制结果」按钮。

**2. 家长发回**

家长用微信把那段文字发给你。可以一份一份发，也可以几份一起发。

**3. 你导入并看结果**

打开管理后台 → 输入口令 → 停在「导入答卷」页 → 把收到的文字整段粘进去 → 点「导入」。

- 重复内容会自动跳过，不怕同一份导入两次
- 一次粘多份（中间空一行）也可以
- 也支持从 `.txt` / `.json` 文件导入

导入后即可看到：

| 页签 | 内容 |
|---|---|
| 分布统计 | 13 道非开放题的逐项人数与占比条 |
| 交叉分析 | 任选一个维度看各选项人数分布 |
| 开放建议 | 家长写的第 14 题原文，按年龄/区域标注 |
| 全部答卷 | 每份答卷逐题展开，可单条删除 |
| 使用说明 | 原表里的样本量、价格题口径、合规提醒等 10 条 |

**导出**：CSV（Excel/WPS 双击打开不乱码）或 Excel（`.xlsx`）。

## 数据存在哪

当前是**无后端模式**：答卷存在你这台电脑的浏览器本地存储里。

- 好处：家长不用注册、不用授权、不上传任何信息，完全匿名
- 代价：**换电脑、换浏览器、或清理浏览器数据前，务必先导出备份**
- 导出的 CSV/Excel 可以随时重新导入，不会丢

若之后想让家长提交后自动入库（无需发回文字），需开通云端数据库；届时只需在 `assets/store.js` 的 `config` 里填入对应配置，家长端和后台代码无需改动。

## 改口令

编辑 `admin.html`，在 `<body>` 上加属性：

```html
<body class="admin" data-pw="你的新口令">
```

## 题目结构

四个板块，对应原表：

1. 孩子与家庭情况（Q01–Q04）
2. 学习需求与关注点（Q05–Q08）
3. 体验形式与付费意愿（Q09–Q13）
4. 开放建议（Q14）

限选规则已在家长端生效：Q05/Q07 最多选 3 项，Q06/Q08 最多选 2 项，超出会拦截并提示。13 道必答题缺任一都会被拦下并定位到第一道未完成的题。

## 文件说明

| 文件 | 用途 |
|---|---|
| `index.html` | 家长填写页（匿名，约 3–4 分钟） |
| `admin.html` | 管理后台（口令进入） |
| `assets/questions.js` | 14 道题目定义（两端共用，改题只改这里） |
| `assets/store.js` | 数据层：结果文字生成 / 解析 / 本地收集箱 / 导出 |
| `assets/survey.js` | 家长端交互 |
| `assets/admin.js` | 后台逻辑 |
| `assets/style.css`、`assets/admin.css` | 暗色主题样式，移动端优先 |

## 本地预览


## 统计口径提醒

所有比例与样本分布仅作市场验证。请关注不同年龄段与区域家长的差异；多选题人数之和会超过总样本数，属于正常。不应以样本数量直接推算全市市场规模。涉及面向儿童的线下培训与课程收费，实施前请向属地主管部门核实合规要求。
